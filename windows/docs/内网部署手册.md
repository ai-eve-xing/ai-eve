## 1. 概述

### 1.1 什么是 AI Eve

AI 夏娃 (AI Eve) 是一款开源的 AI 伴侣应用。支持 CLI 命令行和 Web UI 两种交互方式，具备四层记忆系统、多平台接入能力。

### 1.2 架构特点

```
+-----------------------------------------+
|             用户接入层                     |
|   CLI 终端    Web UI (:10110)            |
+-----------------------------------------+
|             核心引擎 (core/)              |
|   EveAgent -> 四层记忆 -> System Prompt  |
+-----------------------------------------+
|           API 客户端 (cli/api_client.py)  |
|   OpenAI 兼容接口 -> HTTP POST 调用       |
+-----------------------------------------+
|           大模型后端 (外部)                |
|   Ollama / vLLM / 内部 API 网关           |
+-----------------------------------------+
```

### 1.3 关键设计决策（影响内网部署）

| 特性 | 说明 |
|------|------|
| **零外部依赖** | 纯 Python 标准库实现，无需 pip 安装任何第三方包 |
| **自包含 Web 服务器** | 使用 `http.server` 标准库，无需 Nginx/Tomcat |
| **本地持久化** | 记忆数据存储为 JSON 文件，无需数据库 |
| **OpenAI 兼容接口** | 大模型调用走标准 HTTP REST，可对接任意兼容服务 |

## 2. 环境准备

### 2.1 环境需求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Linux kernel 3.10+ | CentOS 7+ / Ubuntu 20.04+ / 麒麟 / 统信 |
| Python | 3.10+ | 3.11 或 3.12 |
| 磁盘空间 | 50 MB（项目本体） | 10 GB+（如需本地大模型） |
| 内存 | 512 MB（仅服务） | 8 GB+（含本地大模型） |
| CPU | 1 Core | 4 Core+（含本地大模型） |
| GPU（可选） | --- | NVIDIA + CUDA 11+（运行本地推理加速） |

### 2.2 检查 Python 版本

```bash
python3 --version
# 预期输出: Python 3.10.x / 3.11.x / 3.12.x

# 如未安装，以 CentOS 为例：
sudo yum install -y python3 python3-pip

# 以 Ubuntu 为例：
sudo apt update && sudo apt install -y python3
```

> **重要**: 本项目使用纯标准库，确认有 `python3` 即可，无需安装任何 pip 包。

### 2.3 端口检查

默认 Web UI 端口为 **10110**，请确保端口未被占用：

```bash
# 检查端口占用
ss -tlnp | grep 10110

# 如需要，可在启动前修改（见 4.3 节）
```

如需对外开放访问，请确保防火墙已放行：

```bash
# CentOS / 麒麟
sudo firewall-cmd --add-port=10110/tcp --permanent
sudo firewall-cmd --reload

# Ubuntu / 统信 UOS
sudo ufw allow 10110/tcp
```

## 3. 项目传输与安装

### 3.1 传输方式（选择一种）

由于是内网环境，请通过以下方式将项目目录传入服务器：

- **USB 介质**: 将项目打包为 tar.gz，通过 USB 拷贝到服务器
- **内网 Git**: 部署内网 GitLab/Gitea，通过 `git clone` 拉取
- **SCP/rsync**: 如有跳板机，通过内网传输
- **光盘介质**: 刻录后挂载拷贝

```bash
# 打包示例（在外网开发机执行）
tar -czf ai-eve.tar.gz /path/to/ai-eve/

# 在目标内网服务器解压
tar -xzf ai-eve.tar.gz -C /opt/
```

### 3.2 两种启动方式 > 决定是否 pip 安装

本项目支持 **两种启动方式**，pip 安装不是必须的：

| 启动方式 | 命令 | 需要 pip 安装？ | 推荐场景 |
|---------|------|:--------------:|---------|
| **模块模式**（推荐） | `python3 -m cli.main` | 不需要 | 内网部署首选，无需联网 |
| **命令模式** | `ai-eve` | 需要 (`pip install -e .`) | 追求命令行简洁 |

> **核心结论**: 内网部署完全不需要 pip 安装，用 `python3 -m cli.main` 或
> `python3 -m cli.main web` 即可启动，零外部依赖。
> 只有在**需要裸命令 `ai-eve`**（不带 `python3 -m`）时才需要 pip。

### 3.3 推荐部署路径

```bash
# 将项目放置到 /opt 或 /usr/local 下
sudo cp -r ai-eve /opt/ai-eve
# 或
sudo mv ai-eve /usr/local/ai-eve
```

### 3.4 pip 安装（仅当需要使用 `ai-eve` 裸命令时）

如果需要裸命令 `ai-eve`，在内网环境下执行 `pip install`：

```bash
cd /opt/ai-eve

# 可编辑模式安装（推荐，后续更新文件后立即生效）
pip install -e .

# 或正式安装
# pip install .
```

**为什么内网也能 pip 安装？**

- 项目 `dependencies = []`，**pip 不会尝试下载任何第三方包**
- 仅注册 `ai-eve` 入口点到系统 PATH
- setuptools 通常随 Python 预装，无需联网下载
- 验证安装：

```bash
# 确认 ai-eve 命令可用
which ai-eve
# 预期输出: /usr/local/bin/ai-eve

ai-eve --help
# 或
ai-eve help
```

### 3.5 验证项目完整性

```bash
cd /opt/ai-eve

# 检查核心文件是否存在
ls -la cli/main.py
ls -la cli/api_client.py
ls -la core/agent.py
ls -la core/memory/memory_manager.py
ls -la ui/web/server.py
ls -la pyproject.toml

# 确认 Python 可识别为模块
python3 -c "import sys; sys.path.insert(0, '.'); from cli.main import load_config; print('模块加载成功')"
```

> 预期输出: `模块加载成功`

## 4. 配置文件详解

### 4.1 配置文件位置

配置文件为 JSON 格式，存储在用户家目录下：

```
~/.ai-eve/data/config/config.json
```

首次运行时会自动创建目录结构。**也可以直接手工创建**该文件。

### 4.2 完整配置模板

```bash
mkdir -p ~/.ai-eve/data/{config,logs,memory,avatars}
```

写入以下内容到 `~/.ai-eve/data/config/config.json`：

```json
{
  "version": "0.1.0",
  "persona": {
    "name": "紫薇",
    "english_name": "ziwei",
    "style": "anime",
    "personality": "知性优雅",
    "greeting": "你好，我是紫薇。很高兴认识你。"
  },
  "model": {
    "provider": "deepseek",
    "api_key": "***",
    "base_url": "http://10.0.0.100:11434/v1",
    "name": "qwen2.5:7b"
  },
  "voice": {
    "enabled": false,
    "provider": "",
    "voice_id": ""
  },
  "platforms": {
    "telegram": { "enabled": false },
    "discord": { "enabled": false },
    "wechat": { "enabled": false }
  },
  "appearance": {
    "style": "anime",
    "theme": "light"
  }
}
```

### 4.3 关键配置说明

| 配置项 | 路径 | 说明 | 内网建议 |
|--------|------|------|---------|
| 人物名称 | `persona.name` | AI 伴侣名字 | 默认"紫薇"，可自定义 |
| 性格描述 | `persona.personality` | AI 性格标签 | 默认"知性优雅" |
| 模型服务地址 | `model.base_url` | OpenAI 兼容 API 地址 | **必须修改为内网地址** |
| 模型名称 | `model.name` | 模型标识 | 根据内网后端填写 |
| API Key | `model.api_key` | 认证密钥 | 如无需认证可留空 |
| VITS 语音 | `voice.enabled` | 语音合成开关 | 内网通常关闭 |

### 4.4 交互式配置方式（可选）

如 Python 环境正常，可直接运行交互式向导：

```bash
cd /opt/ai-eve
python3 -m cli.main setup
```

## 5. 大模型接入方案

AI Eve 使用 **OpenAI 兼容接口**，只需在配置中指定 `base_url` 即可对接任意后端。

### 5.1 方案一：Ollama（推荐，最简部署）

#### 5.1.1 部署 Ollama

```bash
# 安装 Ollama（如可预下载离线包）
# 从 https://ollama.com/download 下载 linux 版本
sudo cp ollama /usr/local/bin/
sudo chmod +x /usr/local/bin/ollama

# 启动服务（默认端口 11434）
ollama serve
```

#### 5.1.2 下载模型

在内网环境，需要先在有网络的机器下载模型文件，然后传输到内网：

```bash
# 有网络环境：下载模型 GGUF 文件
# 或从 Ollama 模型库下载
ollama pull qwen2.5:7b

# 将模型文件拷贝到内网
# 模型缓存位置: ~/.ollama/models/
```

或者直接使用内网已部署的模型服务。

#### 5.1.3 验证 Ollama API

```bash
curl http://localhost:11434/api/generate \
  -d '{"model": "qwen2.5:7b", "prompt": "你好", "stream": false}'
```

#### 5.1.4 配置示例

```json
{
  "model": {
    "provider": "deepseek",
    "api_key": "",
    "base_url": "http://localhost:11434/v1",
    "name": "qwen2.5:7b"
  }
}
```

### 5.2 方案二：vLLM（生产环境，高并发）

vLLM 提供高性能推理，同样暴露 OpenAI 兼容接口：

```bash
# 启动 vLLM（需 GPU 环境）
python3 -m vllm.entrypoints.openai.api_server \
  --model /path/to/model \
  --port 8000 \
  --trust-remote-code

# 对应配置
# base_url: "http://localhost:8000/v1"
# name: "/path/to/model" 或模型名称
```

### 5.3 方案三：企业内部 API 网关

如果企业已有大模型 API 网关（如阿里云专有云、华为云 ModelArts、自研 API 代理），只要暴露 OpenAI 兼容接口即可：

```json
{
  "model": {
    "provider": "deepseek",
    "api_key": "***",
    "base_url": "http://内网网关地址/v1",
    "name": "模型标识"
  }
}
```

### 5.4 无大模型时的降级验证

如暂无大模型后端，可先跳过模型配置。系统会提示"请先配置模型"，但 Web 界面和 CLI 仍可正常启动展示。

## 7. 服务化管理（systemd）

### 7.1 创建 systemd 服务

```bash
sudo tee /etc/systemd/system/ai-eve.service << 'EOF'
[Unit]
Description=AI Eve Service - AI Companion
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ai-eve
ExecStart=/usr/bin/python3 -m cli.main web
Restart=always
RestartSec=5
StandardOutput=append:/var/log/ai-eve.log
StandardError=append:/var/log/ai-eve.log

[Install]
WantedBy=multi-user.target
EOF
```

> **注意**: 如果使用了 `pip install -e .`，可将 `ExecStart` 改为 `ExecStart=/usr/local/bin/ai-eve web`。

### 7.2 启动与开机自启

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start ai-eve

# 查看状态
sudo systemctl status ai-eve

# 设置开机自启
sudo systemctl enable ai-eve
```

### 7.3 日志查看

```bash
# 实时查看日志
sudo tail -f /var/log/ai-eve.log

# 查看最近 100 行
sudo tail -100 /var/log/ai-eve.log

# 使用 journalctl
sudo journalctl -u ai-eve -n 50 --no-pager
```

## 9. 故障排查

### 9.1 问题：Web 页面无法访问

**原因**: 端口未开放或服务未启动

```bash
# 确认服务在运行
ps aux | grep "cli.main"

# 确认端口在监听
ss -tlnp | grep 10110

# 检查防火墙
sudo firewall-cmd --list-ports
```

### 9.2 问题：模型调用失败

**原因**: 大模型后端不可达或配置错误

```bash
# 第一步：确认 base_url 可访问
curl http://内网IP:11434/v1/models

# 第二步：手动测试 API 连通性
curl -X POST http://内网IP:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "qwen2.5:7b", "messages": [{"role": "user", "content": "你好"}], "stream": false}'

# 第三步：检查 config.json 配置
cat ~/.ai-eve/data/config/config.json | python3 -m json.tool
# 确认：
# - base_url 正确（以 /v1 结尾）
# - name 与模型名称匹配
# - API Key 不匹配
```

### 9.3 问题：Python 模块找不到

```bash
# 确认在项目目录执行
cd /opt/ai-eve
pwd   # 应返回项目根目录

# 如仍有问题，手动设置 PYTHONPATH
PYTHONPATH=/opt/ai-eve python3 -c "from cli.main import load_config; print('OK')"
```

### 9.4 问题：记忆文件损坏

```bash
# 记忆文件位置
ls -la ~/.ai-eve/data/memory/

# 备份后重建
cp -r ~/.ai-eve/data/memory ~/.ai-eve/data/memory.bak
# 重启应用后会自动重建空记忆
```

### 9.5 问题：配置文件格式错误

```bash
# 检查 JSON 语法
python3 -m json.tool ~/.ai-eve/data/config/config.json

# 如果报错，检查：
# - 末尾不要有逗号
# - 双引号而非单引号
# - 键名不能使用注释
```

|       +-- token_stats.py        # Token 使用统计

|   +-- __init__.py
|   +-- agent.py                  # EveAgent：核心 AI 对话引擎
|   +-- memory/
|       +-- __init__.py
|       +-- memory_manager.py     # 四层记忆系统
+-- ui/                           # 用户界面
|   +-- web/
|       +-- __init__.py
|       +-- server.py             # HTTP 服务（纯标准库）

|   +-- 内网部署手册.md           # 本文档

>
